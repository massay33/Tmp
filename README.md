# Крестики-нолики (Tic-Tac-Toe)

Классическая игра "Крестики-нолики" на Node.js для игры в консоли.

## Описание

Игра для двух игроков, где нужно собрать три одинаковых знака в ряд (по горизонтали, вертикали или диагонали).

## Установка

```bash
npm install
```

## Использование

Запустить игру можно двумя способами:

```bash
# Через npm
npm start

# Или напрямую через Node.js
node tic-tac-toe.js
```

### Как играть

1. Игра начинается с поля 3×3, пронумерованного от 0 до 8
2. Игроки ходят по очереди (первым ходит X)
3. Введите номер клетки (0-8), куда хотите поставить свой знак
4. Побеждает тот, кто первым соберёт 3 знака в ряд
5. Если все клетки заполнены, но победитель не выявлен — ничья

```
0 | 1 | 2
3 | 4 | 5
6 | 7 | 8
```

## Особенности

- Консольный интерфейс
- Проверка корректности хода
- Определение победителя и ничьей
- Поддержка двух игроков за одним компьютером

## Технологии

- Node.js
- Readline модуль для работы с консолью
