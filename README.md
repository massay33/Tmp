# ✨ Neon Tic-Tac-Toe ✨
### 🎮 Культовая игра в современном неоновом стиле на Node.js

---

## 🌟 Особенности проекта

> **Погрузитесь в атмосферу киберпанка!** Эта версия классической игры "Крестики-нолики" полностью переработана с использованием ярких неоновых цветов, плавных анимаций и современного веб-дизайна.

- 🎨 **Неоновый дизайн**: Яркие цвета (циан и маджента) на тёмном фоне.
- ⚡ **Живые анимации**: 
  - ✨ *Подрагивание* клеток при наведении курсора.
  - 💓 *Пульсация* победной линии.
  - 🌊 Плавные переходы состояний.
- 📱 **Полная адаптивность**: Идеально работает на ПК, планшетах и смартфонах.
- 🖥️ **Две версии в одном**:
  - 🌐 **Веб-интерфейс** (красивый UI в браузере).
  - 💻 **Консольная версия** (классическая игра в терминале).
- 🚀 **Лёгкий запуск**: Минимум зависимостей, быстрый старт.

## 🚀 Быстрый старт

Следуйте этой простой инструкции, чтобы начать игру:

### 1️⃣ Установка зависимостей
Убедитесь, что у вас установлен [Node.js](https://nodejs.org/). Затем выполните команду в терминале:
```bash
npm install
```

### 2️⃣ Запуск веб-версии (Рекомендуется 🔥)
Запустите сервер и откройте игру в браузере для полного визуального наслаждения:
```bash
npm start
```
👉 Откройте в браузере: **http://localhost:3000**

### 3️⃣ Запуск консольной версии
Для любителей ретро-стиля и игры в терминале:
```bash
npm run console
```

## 🎮 Как играть

Правила просты, но захватывающи:

1. 🎲 **Начало**: Игра начинается автоматически. Первый ход делает игрок **❌ (X)**.
2. 👆 **Ход**: Кликните на свободную клетку (в вебе) или введите номер клетки (0-8 в консоли).
3. 🔄 **Смена хода**: Игроки меняются местами (**❌** ↔️ **⭕**).
4. 🏆 **Победа**: Соберите **3 знака в ряд** по горизонтали, вертикали или диагонали.
   - Победитель подсвечивается неоновым сиянием! ✨
5. 🤝 **Ничья**: Если все клетки заняты, а победителя нет — фиксируется ничья.
6. 🔄 **Реванш**: Нажмите кнопку **"Начать заново"** (или введите команду в консоли), чтобы сыграть ещё раз.

## 🎨 Визуальный стиль

Проект выполнен в эстетике **Cyberpunk / Neon**:
- 🌑 **Фон**: Глубокий темный цвет для контраста.
- 🔵 **Игрок X**: Яркий циан (`#0ff`) с эффектом свечения.
- 🟣 **Игрок O**: Насыщенная маджента (`#f0f`) с неоновым ореолом.
- 🔘 **Клетки**: Скругленные углы (`border-radius`), полупрозрачность и эффект стекла.
- 🎭 **Интерактивность**: При наведении курсора клетки "дрожат", приглашая сделать ход.
