# Крестики-Нолики на Node.js

Игра "Крестики-нолики" с современным веб-интерфейсом и красивым дизайном.

## Особенности

- 🎨 **Современный дизайн** с фоновым изображением
- 🌐 **Веб-интерфейс** для игры в браузере
- 💻 **Консольная версия** для игры в терминале
- 📱 **Адаптивный дизайн** для мобильных устройств
- 🎮 **Два режима игры**: веб и консоль

## Установка

```bash
npm install
```

## Запуск

### Веб-версия (рекомендуется)

```bash
npm start
```

Затем откройте в браузере: http://localhost:3000

### Консольная версия

```bash
npm run console
```

## Как играть

1. Игроки ходят по очереди
2. Первый игрок играет за **X** (красный цвет)
3. Второй игрок играет за **O** (бирюзовый цвет)
4. Побеждает тот, кто первым соберёт 3 знака в ряд (по горизонтали, вертикали или диагонали)
5. Нажмите "Начать заново" для новой игры
